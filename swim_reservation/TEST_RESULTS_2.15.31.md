# 2.15.31 · 화면 업데이트 안내 반복 수정

- 원인: 2.15.30 운영 서버가 제공하는 `app.js`의 CLIENT_VERSION 상수가 2.15.29로 남아 있었습니다. Cache-Control은 이미 no-store였으므로 새로고침해도 최신 응답 자체의 버전 불일치가 반복됐습니다.
- 변경: 화면 JS의 고정 버전을 표식으로 교체하고 HTTP 제공 시 같은 설치 패키지의 버전을 삽입합니다. 서버 상태·안전 검사가 같은 APP_VERSION을 사용합니다. 상태 응답을 보고 구버전 화면의 버전을 최신이라고 바꾸지 않으므로 실제 오래된 화면의 안내와 취소 안전 차단은 유지됩니다. 표식 누락·중복은 오류로 처리하고 테스트로 발견합니다.
- no-store 및 고정 정적 파일 허용 목록 유지. 현재 iframe의 재열기 주소만 바꾸고 상위 캠핑 노트 주소·연결 경로·기존 쿼리·선택 페이지를 유지합니다. 새로 열기 취소 시 작성 중 입력 유지. Android APK·서명·저장 형식 변경 없음.
- HTTP 제공·표식 검사·연결 복구·업데이트 안내·취소 차단·재열기 회귀 테스트 12개 통과. 모바일 390px/PC 1280px, sandbox 내장 iframe에서 구버전 2.15.30 → 새로 열기 → 실제 새 코드 및 안내 해제를 검증했습니다. 패키지 버전·애드온 config.yaml 버전 일치도 검사합니다.
- 테스트는 모의 예약 응답만 사용했습니다. 실제 예약·취소·입금은 실행하지 않았습니다.
