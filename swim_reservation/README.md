## 2.15.14 · 사이트 다중 선택과 하단 메시지

사이트 선택 버튼으로 카드 목록을 열고 여러 사이트를 고른 뒤 완료하면 한 번에 추가됩니다. 취소·닫기는 적용하지 않습니다. 조회 결과 갱신 중에도 목록을 유지하고 상태를 갱신하며 기존 드래그 우선순위를 유지합니다. 작업 오류는 하단 플로팅 메시지로 알리고 닫기·자동 숨김을 제공합니다. 예약 엔진·등록 일정·실행 상태 저장 형식은 변경하지 않습니다.

## 2.15.13 · 실행 시각과 일정별 제어

등록 일정 목록에서 실행 예정 시각(한국 시간)·대기/준비/실행/중지/결과를 확인하고 시작·중지·삭제할 수 있습니다. 활성 일정은 시작·삭제가 비활성화되고 중지만 활성화됩니다. 중지 후 버튼 상태를 복원하며 상세 화면의 제어도 같은 상태를 사용합니다. 완료 또는 제출 결과 확인이 필요한 일정의 재시작 제한은 유지합니다.

개별·선택·전체·즉시 시작 확인창은 실제 실행 시각 또는 즉시 시작, 감시 간격·종료 시각과 HA 서버의 전원·절전·애드온 중지/재시작·네트워크 실패 조건을 안내합니다. HA 서버에서 실행하므로 앱의 폰 배터리·권한 안내와 구분합니다. 앱과 애드온에서 같은 예약을 동시에 실행하지 마세요.

# 쉼오지 예약 도우미 Home Assistant App

Home Assistant Ingress 웹 UI와 예약 엔진을 포함합니다. 단독 예약·다중 예약·다인 예약·취소 대기를 지원하며 다인 예약은 객실 수만큼의 인원, 다른 모드는 한 명만 실행합니다. 저장 이력에서 독립 일정 최대 20개 저장·5개 동시 진행과 상세 팝업을 관리합니다. 예약 조회는 저장 예약자 전체를 사람별로 조회하고 1회성 조회는 따로 확인합니다. 쉼오지 서버 시간에 맞춰 실행하며 amd64와 aarch64를 지원합니다.

설치와 사용법은 `DOCS.md`를 참조하세요.

2.15.0은 새 공식 사이트 swimozicamp.com/camp 전환 버전입니다. 오픈 전 사전 입력 없이 실행 시각에 정보·필수 약관을 일괄 입력하고 무통장 예약을 신청합니다. 월별 현황은 날짜별 잔여 수만 제공하며 예약 확정 상태는 예약 조회에서 확인합니다. 자동 입금·온라인 취소·카드 자동 결제는 지원하지 않습니다. 이전 대기 일정은 자동 재개하지 않으므로 확인·수정 저장 후 시작하세요.

2.7.0부터 공개된 GHCR 설치 이미지를 내려받습니다. HA 기기에서 Chromium·폰트·의존성을 직접 설치하는 빌드 과정은 생략하며 기존 데이터 폴더와 예약 설정은 유지합니다. PC/폰 화면은 우측 상단 플로팅 메뉴의 가로 세 줄을 눌러 전환하며, 현재 화면 이름과 선택 색상을 표시합니다.

월별 현황은 한국 시간 이번 달에서 3개월 뒤인 달만 서버에서 미리 조회합니다(2026년 10월 기준 2027년 1월). 기본 1시간 간격이며 월별 탭의 ‘조회 간격 설정’에서 간격을 변경하거나 끌 수 있습니다. 저장 현황과 설정은 재시작 후에도 유지됩니다. ‘조회’는 즉시 갱신을 요청하며 날짜별 조회 완료까지 시간이 걸릴 수 있습니다. 이후 달은 기존처럼 열었을 때 조회합니다. 예약 준비·실행 및 실행 시각 5분 전부터는 미리 조회를 중단하고 예약을 우선합니다. 현황은 조회 시점의 정보이므로 예약 가능이나 성공을 보장하지 않습니다.
