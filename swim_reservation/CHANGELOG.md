# 변경 기록

## 2.15.31

- 화면 버전의 수동 입력을 없애고 실제 제공하는 화면 코드에 패키지 버전을 자동 반영합니다. 최신 화면에서도 업데이트 안내가 반복되던 문제를 수정했습니다.
- 실제 구버전 화면의 안내·취소 안전 검사는 유지합니다. 캠핑 노트 내부 화면의 새로 열기는 상위 앱 주소·연결 경로를 유지합니다. Android 앱 설치 파일과 저장 형식은 변경하지 않습니다.

## 2.15.30

- 앱 0.4.26과 함께 필수 입력 안내를 비강제 방식으로 변경했습니다. 스크롤·이력 확인은 검사하지 않으며 오류 때문에 입력칸으로 이동하거나 키패드를 열지 않습니다.
- 입력칸을 벗어날 때 오류가 있으면 해당 칸 색상과 플로팅으로만 안내합니다. 다음 단계·예약자 저장·일정 등록·예약 실행의 필수 검사는 유지합니다.
- 초기화는 이전 오류·지연 안내를 지우고 입력을 강요하지 않습니다. 저장된 예약자 선택과 한글 조합 중 검사 유예를 유지합니다.

## 2.15.29

- 예약 확인창에 공식 날짜별 평일·주말·성수기 요금과 총 숙박비를 함께 표시합니다. 사이트·기간·인원·날짜 순서·박수·합계를 대조하며, 세부 내역을 확인하지 못하면 추정하지 않습니다.
- 예약 조회 상세에 입실·퇴실·총액·계좌·예금주·입금 기한과 24시간 안내를 표시합니다. 사용자 확인 계좌 안내를 조회 결과의 구조화된 정보로 유지하며 기존 예약 금액은 현재 요금으로 재계산하지 않습니다.
- 사이트 선택창의 배치도 버튼을 오른쪽 끝으로 옮기고 노란색으로 변경했습니다. 앱과 애드온에 동일 적용했습니다.

## 2.15.28

- 예약자 저장 시 누락·형식 오류와 입력 방법을 구체적으로 안내합니다. 입금자명은 비워도 저장됩니다.
- 사이트 선택 팝업에서 배치도를 열고 선택 내용을 유지한 채 돌아올 수 있습니다. 앱 배치도의 애드온 안내 문구를 제거했습니다.
- 바로 예약 기간은 일정 등록·설명을 숨기고 버튼을 ‘예약 하기’로 통일했습니다.
- 예약 확인창에 입실·퇴실·박수, 사이트별 공식 숙박비와 합계, 사용자 확인 계좌를 표시합니다. 우선순위 후보 금액은 합산하지 않으며 미확인 금액은 0원으로 처리하지 않습니다.
- 입금 안내: ‘예약 후 24시간 이내 입금하지 않을 시 자동으로 예약이 취소됩니다.’ 실행 예정 이하 기존 긴 설명은 확인창에서 제거했습니다. 금액 확인은 개인정보 없이 공개 상세 화면 GET만 사용하며 예약 제출·자동 재시도는 하지 않습니다.

## 2.15.27

- 예약자명은 공백 없이 완성된 한글 2~50글자만 허용합니다. 영문·외국어·혼합 이름·숫자·기호 및 한 글자 이름을 차단하며 앱과 애드온의 입력 안내·저장·실행 검증을 일치시켰습니다.
- 기존 예약자·일정 데이터는 삭제하거나 변경하지 않습니다. 한글 조합 중 검사 유예와 저장된 예약자 선택 동작을 유지합니다.

## 2.15.26

- 앱 0.4.21과 함께 예약자명 형식 검증 추가: 미완성 한글 자모·숫자·이모지·단독 기호를 차단하고 정상 국제 이름·띄어쓰기·하이픈·아포스트로피 허용
- 화면 단계 이동, 예약자 저장, 예약 실행에 같은 형식 검증 적용. 기존 저장 자료는 삭제하거나 자동 수정하지 않음
- 한글 조합 중에는 검사 안내·자동 다음 단계 이동을 보류하고 조합 종료 후 판단. 저장 예약자 선택 예외는 유지
- 형식 검증이며 실제 본인 이름을 인증하는 기능은 아님

## 2.15.25

- 앱 0.4.20과 함께 필수 입력 안내 중에도 저장 예약자 목록을 선택할 수 있도록 수정
- 단독·다인 예약의 저장 목록을 여는 동안 포커스 복귀·스크롤 안내·이전 필드 콜백을 중단하고 필수 입력 플로팅 안내를 닫음
- Android 목록 선택 시 키패드를 숨기고 지연된 키패드 표시 요청을 무효화. 직접 입력 및 다음 단계 필수 검사는 유지

## 2.15.24

- 앱 0.4.19와 함께 초기화 전 예약된 필수 입력 안내를 무효화하고 현재 화면의 오류 표시·플로팅 안내·안내 순서를 초기화
- 초기화 후 예약자명부터 다시 안내. 뒤쪽 필드에서 안내를 요청해도 앞선 필수 누락 항목을 우선 안내
- Android는 누락 입력칸에 초점을 맞춘 뒤 네이티브 키패드 표시 요청. 날짜 선택 팝업과 선택 항목은 기존 동작 유지

## 2.15.23

- 앱 0.4.18과 함께 필수 입력 누락 시 색상 강조·해당 칸 이동·플로팅 안내. 다음 단계 진입, 입력칸 이탈, 입력하지 않고 스크롤하거나 접힌 구역을 지나치는 경우 포함
- 선택 항목과 날짜 선택 팝업은 제외하고 정상 입력 후 강조 해제
- 저장 이력을 ‘예약 대기 일정 등록 및 예약 이력’으로 변경. ‘예약 대기 일정 명칭’은 오픈 전 일정에서만 표시
- 새 바로 예약 일정 명칭은 입실일이 아닌 한국 예약 실행일로 기록. 기존 저장 일정은 변경하지 않음

## 2.15.22

- 앱 0.4.17과 함께 사이트 선택 버튼을 객실 선택 제목 오른쪽으로 이동하고 별도 버튼 줄 여백 제거
- 선택 가능한 사이트가 딱 한 개일 때 해당 항목을 체크하면 즉시 적용·닫기. 여러 개는 기존 일괄 선택·완료 방식 유지
- 선택 해제·취소·현황 갱신만으로는 자동 적용하지 않으며 실제 예약 실행과 구분

## 2.15.21

- 앱·애드온 모두 예약자 정보 → 기간 → 객실 선택 순서로 필수 입력 단계 통일

- 앱 0.4.16과 함께 날짜 선택 전 박수 표시 숨김, 시작 확인·안전 안내의 중복 문구 정리
- 앱 예약 대기 시작 시 실행 1시간 전의 짧은 시간 동기화와 실제 배터리 사용이 늘어나는 실행 시각을 구분하여 안내
- 오픈 전 안내에 앱·애드온 공통 1·1·2·3초 간격, 최초 포함 최대 5회·10초 이내 GET 재조회. 중지·시한 초과·403·429·알 수 없는 응답·최종 제출에는 적용하지 않음

## 2.15.20

- 앱 0.4.15와 함께 실행 시각을 ‘예약 실행 시간(오픈 예정일)’로 표시하고 오픈 전 일정에만 자동 계산·읽기 전용 표시
- 날짜 입력 전 즉시 예약 숨김, 월별 달력·이동 버튼 가운데 정렬
- 비회원 조회를 기본 접힘 메뉴와 이름·전화·조회 한 줄 구성으로 통일
- 예약 내역의 상세 버튼을 금액 오른쪽으로 이동하고 목록 간격을 3px로 축소
- 월말 입실 선택 시 다음 달 퇴실 달력 자동 이동, 월별 주기 조회 삭제 및 진입·월 변경 시 조회
- 앱·애드온 범례와 월 이동 버튼 통일, 앱 전체 8개 메뉴 표시 여부를 애드온에서 설정
- 폰 실행 권한 메뉴 대신 기능 사용 시 부족한 권한과 설정 바로가기 안내 (허용 후 자동 예약 시작 없음)

## 2.15.16

- 공식 조회의 ‘자동취소’를 취소 상태로 해석하여 해당 내역 때문에 전체 예약조회가 실패하던 문제 수정
- 자동취소는 결제 완료·예약 확정으로 해석하지 않음. 기존 예약 완료 검증의 입금대기 조건 유지

## 2.15.15

- 실제 서버의 정적 파일 허용 목록에 하단 메시지 스크립트 경로 추가
- 실제 HTTP 서버로 첫 화면에서 참조하는 모든 스크립트의 응답·내용과 허용되지 않은 경로 차단 검증

## 2.15.14

- 앱과 공통으로 사이트 선택 창에서 여러 사이트를 고른 뒤 완료하면 한 번에 반영. 취소·닫기는 기존 선택 유지
- 작업 오류는 하단 플로팅 메시지로 표시하고 닫기·자동 숨김 제공. 모달 안에서도 표시하며 조작 버튼을 가리지 않음
- 사이트의 전체 기간 가능 여부·예정·미확인 구분과 기존 드래그 우선순위는 유지

## 2.15.13

- 개별·선택·전체 시작 확인에 실제 실행 예정 날짜·시각(한국 시간), 감시 간격·종료 시각과 서버 실행 조건 안내
- 저장 일정 목록에서 대기·준비·실행·중지·결과 상태와 실행 시각을 표시하고 시작·중지·삭제 버튼 제공
- 활성 일정은 시작·삭제 비활성화, 중지만 활성화. 중지 후 복원하며 상세 화면에서도 같은 상태 사용
- 앱과 애드온은 독립 실행이며 폰 배터리 안내는 앱에, HA 서버 전원·절전·애드온·네트워크 안내는 애드온에 표시

## 2.15.12

- 앱 0.4.7과 함께 배치도 위쪽 사진 등록 버튼을 숨기고 사진 목록 마지막의 ‘＋ 추가’만 표시
- 등록한 사진마다 다운로드 제공. 선택·적용·삭제와 별개로 저장된 PNG를 내려받으며 사진 이력은 변경하지 않음
- 빈 목록·최대 6장·삭제 후 추가와 다운로드 파일 내용, 앱·애드온 화면 회귀 검증

## 2.15.11

- 앱 0.4.6과 동일한 사이트 추가·삭제·드래그 순위 화면을 사용. 체크박스 전체 나열 방식에서 공통 선택기로 통일
- 전체 숙박 기간 조회에서 같은 사이트로 예약 가능한 곳만 추가 목록에 표시. 날짜별 수량을 합산해 연박 가능으로 판단하지 않음
- 오픈 전 예정은 전체 사이트를 후보로 표시. 취소 대기는 마감 사이트도 감시 후보 지정 가능. 조회 실패·다른 기간 결과는 후보로 사용하지 않음
- 현재 기간에 불가로 확인된 선택은 해제하고 안내. 새로운 날짜·기간은 자동 조회하되 실제 예약 제출은 하지 않음
- 입실·퇴실 달력에 날짜별 가능 수·마감·예정 표시를 앱과 공통으로 유지하고 기존 애드온 날짜 표시 설정을 한번 전환

## 2.15.10

- 입실·퇴실 달력에 예약 가능한 곳 수·마감·예정·미확인을 표시하고 지난 날짜는 선택 차단
- 마감일은 입실 불가, 퇴실 당일은 숙박일에서 제외. 취소 대기에서는 마감·예정 선택 허용
- 연박 가능 여부는 날짜별 개수의 합이 아닌 전체 숙박 기간의 실제 조회 결과로 표시
- 플로팅 초기화는 현재 예약 화면만 초기화하며 다른 모드 초안·저장 예약자·일정은 유지. 비어 있는 화면과 조회·설정 화면에서는 버튼 숨김

## 2.15.9

- 배치도 사진 목록 마지막 칸에 ‘＋ 추가’ 타일을 표시하고 클릭 시 기존 사진 선택·등록 경로로 연결
- 빈 목록에서도 타일 표시, 6장 한도 및 등록·변경 처리 중 비활성화, 삭제 후 추가 재활성화
- 기존 사진 적용·확대·삭제와 예약 엔진 동작은 유지

## 2.15.8

- 월별 현황의 조회 시작·월 이동 중 구사이트의 전체 사이트 목록이 잠깐 나타나는 현상 제거
- 날짜별 수량을 한 줄의 N곳으로 간결하게 표시하며 예약 가능은 초록색, 잔여 없음은 붉은색, 오픈 전·미확인은 회색으로 구분. 조회 중은 별도 표시
- 수량 전용 달력 높이 축소 및 범례 교체. 월별 조회 실패는 미확인으로 유지하고 날짜별 추가 요청으로 확대하지 않음

## 2.15.7

- 예약 조회 목록은 사이트·날짜·금액·상태를 낮은 높이로 표시하고 예약번호·입금 기한·전화 취소 안내는 상세 펼침으로 제공. 등록 일정 목록도 간격 축소
- 공식 사이트의 현재 빈 결과 안내를 정확히 인식하여 정상 0건으로 처리. 불명확한 결과·다른 오류는 계속 검증 실패로 처리
- 2.15.6 예약자 추가·제외 카드 개선을 함께 운영 배포

## 2.15.6

- 예약 대기 중 객실 조회가 사전 준비 세션의 공유 Chromium을 닫아 `locator.evaluateAll` 오류를 일으키던 문제 수정
- 최근 1,000건의 실행 과정과 오류를 `/data`에 저장하고 조회·복사·텍스트 파일 저장이 가능한 실행 로그 영역 추가

## 1.3.0

- 예약자 정보를 최대 2개까지 서로 독립적으로 저장하고 `예약자 2명 사용`을 기본 OFF로 제공
- 예약자 1의 실제 완료 화면이 확인된 경우에만 예약자 2를 시작하는 엄격한 순차 처리 및 예약자별 상태 표시
- 우선순위 후보와 각 예약자 세션을 최종 제출 직전까지 순서대로 준비하고, 명확한 객실 마감 응답일 때만 다음 순위를 시도
- 후보 수와 예약자 수에 따라 사전 준비를 30초~5분 전에 시작하도록 조정
- 사전 준비 후보들은 Chromium 프로세스 하나의 독립 컨텍스트를 공유해 미니 PC 메모리 사용을 줄이고, 오픈 전 데이터가 없으면 실패 처리하지 않고 오픈 시 최신 페이지로 진행
- 예약 사이트 `Date` 헤더를 여러 번 측정해 가장 짧은 RTT 샘플로 서버 시각을 동기화하고, 스케줄러도 동기화 시각을 기준으로 실행
- 서버 시간·마지막 동기화·추정 시간 차이·RTT·동기화 상태 표시 및 5분 주기 재동기화
- 예약 오픈 전과 대기 중에도 서버가 제공한 객실 상태를 표시하고, 데이터 미제공 시 추정하지 않는 별도 상태 추가
- 모바일에서 Ingress 내부 리다이렉트가 외부 브라우저의 인증 쿠키를 잃어 401이 되던 문제를 제거하고, 인증된 API로 외부 예약 확인 URL을 받은 뒤 직접 이동
- `예약확인 사이트 이동` 문구와 주변 버튼 스타일 통일
- `설정 저장`을 4번 저장 이력으로, `사이트 위치 안내`를 2번 객실 우선순위로 이동
