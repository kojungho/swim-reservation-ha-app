# 변경 기록

## 1.2.10

- 저장된 예약자명과 휴대폰 번호로 사이트의 `예약 확인 및 취소` 페이지를 바로 여는 버튼 추가
- 한글 예약자명을 사이트 형식에 맞는 EUC-KR 주소로 안전하게 변환

## 1.2.9

- 예약 오픈 전에도 예약 페이지를 확인해 객실별로 `예약 가능 (예약 오픈 전)` 또는 `예약 불가 (예약 오픈 전)` 표시
- 선택한 숙박 날짜의 `예약 가능 시작 일시`를 날짜·시각 영역과 객실 확인 결과에 표시

## 1.2.8

- 내부 단계 코드 `reservation-error` 등을 알아보기 쉬운 한글 단계명으로 표시
- 성공 상태와 완료 단계를 모두 `예약 완료`로 명확하게 표시
- 저장된 오류 진단이 `order_ok4.php` 완료 화면이면 App 재시작 시 예약 완료 상태로 자동 보정
- 예약 오픈 전에는 모든 객실 옆과 객실 확인 결과에 `예약 오픈 전` 상태를 표시

## 1.2.7

- 최종 제출 후 이동하는 `order_ok4.php`를 예약 완료 화면으로 판정
- 완료 화면의 `예약자 정보` 문구를 개인정보 입력 단계로 오인하던 문제 수정
- 복수 객실의 실제 성공 결과가 실패로 집계되던 문제 수정

## 1.2.6

- 객실 상태를 `예약 가능`, `예약 완료`, `해당 박수 불가`, `예약 오픈 전`으로 구분
- 체크박스가 비활성화된 객실은 박수 선택지가 남아 있어도 예약 완료로 판정

## 1.2.5

- 예약 30초 전에 객실 선택, 환불 동의와 예약자 정보 입력까지 완료
- 지정된 예약 실행 시각에는 마지막 **예약하기** 버튼만 클릭
- 준비 소요 시간을 반영해 남은 시간을 다시 계산하여 최종 제출 시각 지연 방지
- 최종 결과가 명확한 객실 마감이면 실패 객실을 제외하고 다음 우선순위로 자동 재시도
- 숙박 날짜·박수 변경 시 객실별 가능 여부 자동 표시, 오픈 전 날짜는 별도 표시
- 제공된 캠핑장 위치 안내 이미지를 팝업 버튼으로 표시
- `1개 우선순위 예약`과 `여러 객실 동시 예약`을 명확히 분리
- 여러 객실 모드에서 객실별 PHP 세션을 독립 준비하고 지정 시각에 최종 제출을 동시 실행
- 동시 예약 결과를 객실별 성공·실패로 구분해 표시

## 1.2.4

- 예약 오픈 시각 전에는 **지금 바로 예약** 실행 차단
- 첫 페이지와 후속 페이지의 `adaystart`를 선택한 숙박 날짜와 대조하고 불일치 시 즉시 중단
- 실행 상태에서 숙박 시작 날짜, 15초 전 브라우저 준비 시각, 실제 예약 요청 시작 시각을 별도 표시

## 1.2.3

- 생년월일의 연·월·일 분할 `select`와 한 자리 월·일 값 지원
- 환불 규정 페이지의 안내 문구를 예약자 입력 페이지로 오인하지 않도록 판별 순서 개선

## 1.2.2

- 새 실행을 시작할 때 이전 실패 진단 정보 초기화
