# 변경 기록

## 1.2.4

- 예약 오픈 시각 전에는 **지금 바로 예약** 실행 차단
- 첫 페이지와 후속 페이지의 `adaystart`를 선택한 숙박 날짜와 대조하고 불일치 시 즉시 중단
- 실행 상태에서 숙박 시작 날짜, 15초 전 브라우저 준비 시각, 실제 예약 요청 시작 시각을 별도 표시

## 1.2.3

- 실제 `order_ok2.php` 필드명(`name`, `name2`, `tel1~3`, `birthYear/Month/Day`) 대응
- 생년월일의 연·월·일 분할 `select`와 한 자리 월·일 값 지원
- 환불 규정 페이지의 안내 문구를 예약자 입력 페이지로 오인하지 않도록 판별 순서 개선

## 1.2.2

- 실패한 실제 PHP 페이지의 폼·필드·버튼·iframe 구조 진단 수집
- 입력값, 쿠키, 브라우저 저장소 및 전체 HTML을 제외한 안전한 진단 정보 복사 기능
- 새 실행을 시작할 때 이전 실패 진단 정보 초기화

## 1.2.1

- PHP 테이블 HTML의 행 제목과 왼쪽 셀을 이용한 개인정보 필드 탐지
- 입력칸 `name`, `id`, 분할 전화번호와 6자리 생년월일 대응
- 개인정보를 제외한 필드 구조 진단 메시지 추가
- 구체적인 예약 오류 상태가 `exception`으로 덮이지 않도록 개선
