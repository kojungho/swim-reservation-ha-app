# 2.15.38 · 매일 전체 사이트 사전 대조 및 앱 전달

- 매일 오전 10시(한국 시간), 지연 시 19시 전 일일 점검에서 공개 달력의 예약 가능한 날짜를 잔여 수 순으로 최대 7개 고릅니다. 여러 날짜의 목록에서 신규 번호를 수집하고 기존·발견 번호 모두의 공개 `site.php` 상세를 GET으로 확인합니다. 마감된 기존 사이트도 제목·번호·기간을 대조합니다. 번호 변경·재사용은 실제 이름 기준으로 반영하며, 공식 공개 목록에 전혀 나타나지 않는 새 사이트를 예측하거나 번호를 무작위 탐색하지 않습니다.
- 최대 128개 사이트, 요청 사이 500ms 간격, 기존 전체 점검 2분·19시 종료 제한을 유지합니다. HTML·URL·폼의 식별값과 전체 이름 중복을 확인한 뒤 별도 0600 정상 스냅샷에 확인 시각을 기록합니다. 중간 오류·동시 목록 변경 시 공개 정상 스냅샷은 교체하지 않습니다. 대기 일정의 선택 이름을 연결할 수 없으면 미리 확인 필요 알림을 보냅니다. 예약 상태·저장된 선택 이름은 바꾸지 않습니다.
- 정상 스냅샷을 만든 뒤 기존 양식·약관·무통장입금 점검을 최종 제출 직전까지 진행합니다. GET/HEAD 이외 네트워크 차단과 checkOnly 검증을 유지하며 예약 제출·예약 기록 생성은 하지 않습니다. 정상 결과는 로그만, 오류는 HA 모바일 알림입니다. 강화된 일일 점검은 업그레이드 당일 한 번 수행되도록 키를 구분합니다.
