예약 모드별 사용 방법

    

    

      1개 예약 · 우선순위 방식
      
공통 객실 순위를 사용해 예약자마다 객실 하나를 예약합니다. 예약자가 여러 명이면 순서대로 진행합니다.

      
  1. 객실을 체크하고 ⠿ 손잡이를 끌어 위에서부터 원하는 순서로 정합니다.
  2. 예약자 정보를 입력합니다. 최대 5명까지 추가할 수 있습니다.
  3. 날짜·박수·실행 시각을 확인하고 ‘예약 대기 시작’ 또는 ‘지금 바로 예약’을 누릅니다.

      
객실이 확실히 마감된 경우 다음 순위를 시도합니다. 앞 예약자가 실패하거나 결과가 불확실하면 이후 예약자는 중단합니다.

    

    

      여러 객실 동시 예약
      
선택한 예약자 한 명으로 체크한 객실을 모두 예약하는 방식입니다. 순위별 대체 예약이 아닙니다.

      
  1. 동시에 예약할 객실을 최대 5개까지 체크합니다. 표시 순서는 예약 우선순위가 아닙니다.
  2. 예약자 정보 영역의 ‘여러 객실을 예약할 예약자’에서 사용할 한 명을 선택합니다. 나머지 사람의 정보는 유지되지만 실행하지 않습니다.
  3. 날짜·박수·실행 시각을 확인하고 대기 또는 즉시 예약을 실행합니다.

      
체크한 객실 수만큼 실제 예약이 생성될 수 있습니다. 일부 객실만 성공할 수 있으니 완료 후 예약확인에서 결과를 확인하세요.

    

    

      예약자별 동시 예약 · 우선순위
      
최대 5명의 예약자를 동시에 진행하고, 각 사람의 우선순위에 따라 객실 하나씩 예약합니다.

      
  1. 예약자 정보를 입력하고 필요한 사람을 추가합니다.
  2. 각 예약자의 객실 우선순위에서 후보를 체크하고 ⠿ 손잡이로 순서를 정합니다. 개인별 순위는 이 모드에서만 사용합니다.
  3. 날짜·박수·실행 시각을 확인하고 대기 또는 즉시 예약을 실행합니다.

      
같은 객실을 여러 사람의 1순위로 선택하면 서로 경쟁할 수 있습니다. 확실한 마감만 다음 순위로 넘어가며, 결과가 불확실하면 그 사람의 추가 제출을 중단합니다.

    

    
예약 대기와 즉시 예약
예약 대기는 사이트가 허용하는 경우 정보 입력까지 미리 준비하고, 서버 시간에 맞춰 지정 시각에 최종 제출합니다. 오픈 전 다음 단계 접근이 제한되면 지정 시각에 처음부터 진행합니다. ‘지금 바로 예약’은 기다리지 않고 진행하지만 오픈 전에는 실행할 수 없습니다. 네트워크 지연 때문에 서버 도착·완료 시각까지 같지는 않습니다.
‘예약자 정보 저장’은 사람 정보만 별도로 저장합니다. 날짜·박수·모드·객실 순위는 ‘설정 저장’으로 저장하며, 예약 실행 시에도 현재 설정을 저장합니다.

  
  
    
월별 전체 예약 현황

    

    

    
가 예약 가능완 예약 완료대 예약 대기불 1박 불가? 확인 불가

    
날짜를 누르면 숙박 시작 날짜에 반영하고 예약 매크로 화면으로 이동합니다. 오픈 전이나 월별 현황이 없는 날짜는 개별 날짜 링크로 하나씩 확인합니다. 조회 중·실패는 예약 가능 또는 완료를 뜻하지 않습니다. 개별 조회는 1박 기준이며 연속 박수는 별도로 확인해 주세요. 창을 닫거나 달을 바꾸면 진행 중인 조회를 중단합니다.
