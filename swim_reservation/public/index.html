여러 일정 진행

현재 입력한 설정을 별도 일정으로 등록한 뒤 목록의 시작을 누르세요. 미래 시각 예약과 취소 자리 감시는 여기서 등록·시작합니다. 등록 후 다른 날짜·모드로 변경해도 진행 중인 일정에는 영향을 주지 않습니다. 최대 20개 저장, 5개 동시 진행.

기존 일정 수정 중 · 저장 후 시작을 눌러야 실행됩니다.

예약 방식이나 객실 순위 없이 체크한 객실 중 날짜·박수 조건에 맞는 자리가 나오면 선택한 예약자 한 명으로 객실 하나를 즉시 예약합니다. 조회 사이에 마감될 수 있으며 불확실한 제출 결과는 자동 재시도하지 않습니다.

예약 모드별 사용 방법

    

    

      1개 예약 · 우선순위 방식
      
선택한 예약자 한 명으로 우선순위 중 객실 하나를 예약합니다.

      
  1. 날짜·박수·실행 시각과 예약자 한 명의 정보를 선택하거나 입력합니다.
  2. 객실을 체크하고 두 줄 손잡이를 끌어 원하는 순서로 정합니다.
  3. 미래 시각 예약은 아래 여러 일정 진행에서 등록한 뒤 목록의 시작을 누릅니다. 실행 시각이 지났고 예약이 오픈된 경우 ‘지금 바로 예약’을 사용할 수 있습니다.

      
객실이 확실히 마감된 경우에만 다음 순위를 시도합니다. 제출 결과가 불확실하면 중복 방지를 위해 중단합니다.

    

    

      여러 객실 동시 예약
      
선택한 예약자 한 명으로 체크한 객실을 모두 예약하는 방식입니다. 순위별 대체 예약이 아닙니다.

      
  1. 날짜·박수·실행 시각과 예약자 한 명의 정보를 입력합니다.
  2. 동시에 예약할 객실을 최대 5개까지 체크합니다. 객실 우선순위는 없습니다.
  3. 미래 시각 예약은 여러 일정 진행에서 등록한 뒤 목록의 시작을 누릅니다. 실행 시각이 지났고 예약이 오픈된 경우 ‘지금 바로 예약’을 사용할 수 있습니다.

      
체크한 객실 수만큼 실제 예약이 생성될 수 있습니다. 일부 객실만 성공할 수 있으니 완료 후 예약확인에서 결과를 확인하세요.

    

    

      취소 자리 감시
      
감시 마감을 비워두면 숙박 시작일 00시에 종료하며 당일 예약은 하지 않습니다. 마감을 직접 지정하면 그 시각을 우선 적용하므로 당일 감시도 허용할 수 있습니다. 일정 목록에 마감이 표시되며 저장·불러오기와 재시작 후에도 유지됩니다.

      
예약자 한 명과 숙박 날짜·박수·예약해도 되는 객실을 지정합니다. 전체 선택·해제로 객실을 한꺼번에 지정할 수 있습니다. 객실 우선순위와 실행 시각은 지정하지 않습니다.

      
여러 일정 진행에서 감시 일정을 등록한 뒤 목록의 시작을 누르세요. 조건에 맞는 자리가 나오면 객실 하나를 즉시 예약합니다. 제출 결과가 불확실하면 자동으로 다시 예약하지 않습니다.

    

    

      예약자별 동시 예약 · 우선순위
      
최대 5명의 예약자를 동시에 진행하고, 각 사람의 우선순위에 따라 객실 하나씩 예약합니다.

      
  1. 저장된 예약자를 선택하거나 직접 입력하고 필요한 사람만 추가합니다. 신규 예약자는 ‘예약자 저장’으로 목록에 추가할 수 있습니다.
  2. 각 예약자의 객실 우선순위에서 후보를 체크하고 두 줄 손잡이로 순서를 정합니다. 개인별 순위는 이 모드에서만 사용합니다.
  3. 날짜·박수·실행 시각을 확인하고 여러 일정 진행에서 등록한 뒤 목록의 시작을 누릅니다. 실행 시각이 지났고 예약이 오픈된 경우 ‘지금 바로 예약’을 사용할 수 있습니다.

      
같은 객실을 여러 사람의 1순위로 선택하면 서로 경쟁할 수 있습니다. 확실한 마감만 다음 순위로 넘어가며, 결과가 불확실하면 그 사람의 추가 제출을 중단합니다.

    

    
예약 대기와 즉시 예약
미래 시각 예약과 취소 자리 감시는 여러 일정 진행에서 등록한 뒤 목록의 시작을 누릅니다. 예약 대기는 사이트가 허용하는 경우 정보 입력까지 미리 준비하고, 서버 시간에 맞춰 지정 시각에 최종 제출합니다. 오픈 전 다음 단계 접근이 제한되면 지정 시각에 처음부터 진행합니다. ‘지금 바로 예약’은 실행 시각이 미래이거나 서버 시간이 미확인인 경우 표시하지 않으며 오픈 전에는 실행할 수 없습니다. 네트워크 지연 때문에 서버 도착·완료 시각까지 같지는 않습니다.
‘예약자 정보’ 탭은 실제 예약에 사용할 사람들을 관리합니다. 각 모드에 선택 목록은 자동 표시되지만 사람을 선택하기 전에는 입력란을 채우지 않습니다. 일정 등록 후에는 선택과 입력을 초기화합니다. ‘예약 조회’ 탭의 저장 정보는 이름·휴대폰 번호만 별도 보관하며 예약 실행에 사용하지 않습니다. 등록된 일정의 설정은 이후 편집과 관계없이 유지됩니다.

  
  
    
월별 전체 예약 현황

    

    
3개월 뒤 현황 미리 조회 설정
이번 달에서 3개월 뒤인 달만 서버에서 미리 조회합니다. 그 이후 달은 기존처럼 열었을 때 조회합니다.

    

    
가 예약 가능완 예약 완료대 예약 대기불 1박 불가? 확인 불가

    
한국 시간 기준 지난 날짜는 조회하지 않으며 선택할 수 없습니다. 오늘 이후 날짜를 누르면 숙박 시작 날짜에 반영하고 예약 매크로 화면으로 이동합니다. 오픈 전이나 월별 현황이 없는 날짜는 개별 날짜 링크로 하나씩 확인합니다. 조회 중·실패는 예약 가능 또는 완료를 뜻하지 않습니다. 개별 조회는 1박 기준이며 연속 박수는 별도로 확인해 주세요. 창을 닫거나 달을 바꾸면 진행 중인 조회를 중단합니다.
