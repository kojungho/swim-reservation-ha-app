## 사진 확인과 수정

- 제공 사진의 배터리 예외 상태는 이미 허용이었다. 기존 버튼은 설정 목록이 아니라 예외 허용 요청을 보냈다. 실제 배터리 설정 목록 열기와 허용 요청을 분리했으며, 이미 허용된 경우 재요청 대신 상태 안내를 표시한다. 기기가 설정 목록 동작을 지원하지 않으면 앱 정보 화면을 연다.
- 기존 애드온의 하늘존 8개·산맥존 6개 목록을 읽어 네이티브 다중 체크 선택과 우선순위 위·아래·제거 UI를 추가했다. 목록은 실시간 잔여 정보가 아니다. 선택한 우선순위 중 객실 1개 예약 기능이며 다인·다중 예약은 아직 지원하지 않는다.
- 공식 예약 페이지는 선택한 입실일의 한국 시간 `adaystart`를 포함한다. 공식 예약 내역 조회 버튼은 별도 `order_ok7.php`로 분리했다. 두 URL 모두 예약자 개인정보를 포함하지 않는다.
- 실패 상태를 ‘대기’로 표시하던 문구를 ‘오류’로 구분하고, 403은 원인 확정 없이 접속 거부로 안내한다.

## 테스트

전용 읽기 전용 에뮬레이터(Android 17 / arm64 / 16KiB)에서 **53개 검증 항목 통과**. 실제 예약·취소 요청은 보내지 않았다.

기존 43개 안전·절전·예약 시각 알람 검증에 다음 10개 항목을 추가했다.

1. 14개 사이트 목록이 중복 없이 제공됨.
2. 하늘존 8개·산맥존 6개 구성이 기존 애드온과 일치함.
3. 객실 우선순위 중복 제거와 순서 변경.
4. 공식 예약 URL의 선택 입실일·한국 시간 검증.
5. 공식 예약/내역 링크 분리 및 예약자 필드 미포함.
6. 배터리 설정 버튼이 설정 목록 동작을 사용함.
7. 예외 허용 요청이 별도 시스템 동작임.
8. 실제 네이티브 선택 창의 체크 순서가 예약 일정에 반영됨.
9. 선택 창을 취소하면 기존 선택이 유지됨.
10. 선택 객실·순서가 암호화 저장 후 복원됨.

설정 목록 Intent를 에뮬레이터에서 실행해 `Status: ok`, `com.android.settings/.spa.SpaActivity` 진입도 확인했다. 삼성 등 사용자의 실제 기기에서는 아직 수정 버전 테스트를 하지 못했다. 사이트 선택 창 스크린샷도 시각 확인했다.

## 남은 실제 사이트 제한

제공 사진에서 모의 예약은 완료됐으나 실제 앱 조회와 일반 Chrome 접속은 모두 HTTP 403이었다. 앱의 날짜 포함 객실 조회도 예약자 입력 전에 거부됐다. 예약자 정보 부족 때문이라고 단정할 근거는 없으며, 서버 자체·앞단 보안 장비 중 어느 곳에서 거부했는지도 확정하지 못했다.

이번 링크·설정·선택 UI 수정은 403 해결을 의미하지 않는다. 실제 예약 성공은 여전히 검증하지 못했다. 접근 제한을 우회하거나 자동 재전송하는 변경은 하지 않았다.
