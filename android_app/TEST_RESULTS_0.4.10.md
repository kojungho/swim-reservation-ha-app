# 예약조회 수정 검증

- 기존 APK 0.4.7 자산과 공식 읽기 응답을 비교하여 ‘자동취소’ 상태 누락으로 결과 검증이 실패하는 것을 재현. 개인정보·예약 식별값·CSRF/선택 토큰은 저장소/로그에 기록하지 않음.
- 수정된 읽기 코드로 기존 캡처 응답이 모두 인식되는 것을 확인. 실제 예약·취소·결제 요청은 실행하지 않음.
- Node 관련 18개 확인: 자동취소 혼합 목록, 공개 번호 없는 상세 선택, 명의/식별값/주소/CSRF/429/중복 검증 및 예약 완료 오인 방지. 새 앱 읽기 검증 테스트는 MIME과 함수 호출을 보정 후 재실행 통과.
- JVM/Robolectric 16개, Android release/test APK 빌드와 lint 성공. 공개 번호 null, 미래 대기 중 조회, 공유 프로필 실제 실행 중 차단, 잘못된 예약자 검증 포함. 실제 System WebView의 프로필 동작은 실기기에서 검증하지 않음.
- 기존 서명 키가 없어 APK 업데이트는 미배포. public update.json은 0.4.7 유지.
