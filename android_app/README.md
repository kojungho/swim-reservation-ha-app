# 쉼오지 폰 예약 — 독립 안드로이드 앱

배포 명명 규칙: 표시 버전 `X.Y.Z`, APK `swim-phone-X.Y.Z.apk`, 태그 `phone-vX.Y.Z`. 이후 배포에는 preview 접미사나 사전 릴리스 표기를 사용하지 않습니다. 기존 preview 릴리스는 이전 버전 복구용으로 보존합니다.

## 0.4.5 · 2026-10-25

Android 8.0(API 26) 이상, HA 서버 없이 폰에서 실행하는 개인 검증용 APK입니다. 공식 사이트는 https://www.swimozicamp.com/camp/ 입니다. HA 애드온 코드·운영 설정·실행 상태는 변경하지 않습니다.

설치 파일: `dist/swim-phone-0.4.5.apk`. 이전 APK와 같은 디버그 서명으로 업데이트 설치합니다. 파일명과 표시 버전에서 preview 표기를 제거했습니다. 이 명칭 변경은 스토어 출시나 실제 예약 검증 완료를 뜻하지 않습니다. 실제 폰의 예약 성공은 아직 검증하지 않았습니다.

0.4.4는 앱 내부 다운로드·파일 해시/패키지/버전/서명 검증 후 Android 설치 화면 연결을 추가합니다. 외부 브라우저를 열지 않으며 출처 허용과 최종 설치 확인은 사용자가 직접 진행합니다. 예약 중에는 설치를 진행하지 않습니다. 날짜 달력은 가능 수·마감·예정·미확인을 구분하고 퇴실일 제외 규칙을 적용합니다. 초기화는 현재 예약 모드만 비우며 다른 모드 초안은 유지하고 빈 화면에서는 버튼을 숨깁니다. HA 2.15.10도 달력·초기화 변경을 포함하지만 운영 중 애드온을 자동 재시작하지 않습니다.

0.4.3은 앱의 구사이트 날짜 확인 숫자를 제거하고 입실일·퇴실일을 기본 입력으로 사용합니다. 기존 표시 설정은 최초 한 번 새 기본 방식으로 전환하며 저장된 예약 날짜·박수는 바꾸지 않습니다. 이후 사용자가 설정에서 이전 박수 입력 방식을 선택하면 유지합니다. 퇴실일 변경은 자동 계산한 박수·빈자리 표시 무효화·초안 저장에 함께 반영합니다. 애드온의 날짜 UI·예약 이력·로그 처리는 이번 앱 변경에 포함하지 않습니다.

0.4.2는 배치도 사진 목록 마지막 칸의 ‘＋ 추가’ 타일을 추가한 선택 디자인 업데이트입니다. 사진이 없어도 표시하며, 6장이 차면 비활성화하고 삭제 후 다시 추가할 수 있습니다. 기존 사진 선택·등록 버튼도 유지합니다. 예약 엔진과 로그 처리에는 변경이 없습니다.

## 이번 버전에 연결한 기능

- 단독 우선순위 예약, 선택 사이트 모두 예약, 예약자별 우선순위 예약, 시각 예약, 취소 자리 감시를 지원합니다. 예약자·등록 일정은 각각 최대 20개, 활성 일정은 한 개입니다.
- 폰 WebView의 쿠키 저장소는 프로세스에서 공유됩니다. 다인·다중은 세션을 정리하고 **순차 실행**합니다. PC 애드온의 동시 실행과 다릅니다. 제출 간격은 0~60초이며 0초도 병렬 제출이라는 뜻은 아닙니다.
- 사이트 목록의 화면 화살표를 없애고 손잡이 드래그로 정렬합니다. 키보드 방향키도 지원하며 Escape·터치 취소 시 원래 순서를 복원합니다. 행 간격을 줄이고 선택 순위를 동그라미 숫자로 표시합니다.
- 실제 빈자리 조회 결과를 날짜·박수·성인 수에 연결해 가능/잔여 없음/미확인 색상으로 표시합니다. 조건이 바뀌면 이전 결과를 적용하지 않습니다.
- 다인 화면은 사람별 저장 예약자·선택 입금자명·휴대폰·사이트 우선순위를 제공합니다. 카드 오른쪽 위 삭제, 아래쪽 추가 버튼을 배치했습니다.
- 앱 안에서 저장 예약자 전체 또는 직접 입력한 한 명의 예약을 조회합니다. 공식 원본 조회 폼과 상세 선택 POST만 사용하며 실제 예약을 생성하거나 취소하지 않습니다. 목록은 촘촘하게 표시하고 상세를 펼칩니다.
- 월별 예약 가능 개수를 앱 안에서 조회합니다. 0곳은 붉은색, 가능한 날짜는 녹색, 확인 불가는 회색입니다. 오픈 전 서버가 제공하지 않는 가능 여부는 추측하지 않습니다. 월 이동 시 이전 사이트 목록을 표시하지 않습니다.
- 서버 Date 헤더와 왕복 지연으로 시각을 보정하고 알람에 적용합니다. 최근 10분 내 유효한 동기화와 폰 시각을 구분합니다. 실행 중에는 동기화를 차단하며 정밀한 최종 제출 시각을 보장하지 않습니다.
- 공식 목록에서 검증된 사이트 ID·이름을 갱신하고 암호화해 저장합니다. 기존 번호/이름 충돌, 알 수 없는 구조는 중지합니다.
- 취소 감시는 최소 10분 간격이며 사용자 종료 시각을 지원합니다. 조회 사이에는 CPU 잠금을 해제합니다.
- 배치도 사진을 직접 선택해 최대 6장까지 폰 내부에 보관합니다. 적용·크게 보기·선택 삭제·전체 삭제·기본 배치도 복원을 지원하며 HA에 업로드하지 않습니다.
- 모드별 입력 초안을 암호화해 보존합니다. 메뉴 전환 후 복원하며 완료한 실행과 같은 초안만 초기화합니다. 새로 편집한 초안은 보존합니다. 플로팅 초기화는 확인 후 현재 화면의 초안만 지우며 저장 예약자·등록 일정·실제 예약은 삭제하지 않습니다.

## 예약과 오류 처리

예약정보 화면에서 사이트·기간·인원·전송 주소·CSRF를 대조한 뒤 예약자 정보·무통장·필수 약관을 한 번에 입력합니다. 입금자명은 선택이며 비우면 예약자명입니다. 성인 1~2명, 도착 시간·요청사항은 선택이며 생년월일은 사용하지 않습니다. 숨김 보안값이나 선택 마케팅 동의는 바꾸지 않습니다.

결제는 무통장 신청만 지원하며 입금은 직접 해야 합니다. 공식 사이트가 제공하지 않는 카드 결제·온라인 취소는 추가하지 않습니다. 조회 상세에서 취소 연락 안내를 제공합니다. 오픈 전 조회 제한·403·인증을 우회하지 않습니다.

최종 클릭 전에 내구성 제출 마커를 저장합니다. 영수증의 예약 식별값·예약자·사이트·기간·박수·인원·입금 대기를 대조한 경우에만 성공입니다. 429·전송 후 연결 실패·불확실한 영수증은 자동 재제출하지 않습니다. 다인·다중도 불확실한 오류가 나면 남은 제출을 멈추고 확인된 성공은 보존합니다. 공식 내역을 확인한 후 사용자가 제출 잠금을 해제해야 합니다.

조회 실패를 예약 0건이나 빈자리 0곳으로 처리하지 않습니다. 단계별 오류를 기록하고 폰 결과 알림으로 안내합니다. 로그에는 개인정보·응답 본문·CSRF·임의 쿼리를 남기지 않습니다. 화면 예약자 표시는 가운데를 가립니다.

## 설치 후 확인

1. APK를 설치하고 설정에서 알림, 정확한 알람, 배터리 예외를 확인합니다.
2. 먼저 모의 예약 엔진 테스트를 실행합니다. 실제 사이트에는 제출하지 않습니다.
3. 실제 객실 조회가 폰에서 되는지 확인합니다. 403·429는 중지하고 사이트 안내를 따릅니다.
4. 실제 실행은 약관을 확인하고 동의·네이티브 확인창을 거칩니다. **같은 예약을 HA와 폰에서 동시에 실행하지 마세요.**

화면 잠금과 전원 꺼짐은 다릅니다. 전원 꺼짐·방전·강제 중지·제조사 절전 제한·네트워크 단절에서 무중단/정시 실행을 보장하지 않습니다. 미래 시각 대기에는 알람만 등록하며 실행·감시 중에만 지속 알림을 유지합니다. 10초 넘게 늦게 시작한 시각 예약은 자동 제출하지 않습니다. 재부팅/업데이트 시 미래 알람만 복원하고 처리 중이던 예약은 재실행하지 않습니다.

## 업데이트

앱 시작 및 백그라운드에서 돌아올 때마다 공개 `android_app/update.json`을 확인합니다. 동시에 발생한 요청은 하나로 합치고 HTTP 캐시를 사용하지 않습니다. 설정에서 수동 확인도 가능합니다. 실행/대기 중에는 조회·업데이트 안내를 보류하고 기존 작업을 중단하지 않습니다.

디자인·일반 개선은 선택 업데이트입니다. ‘나중에’로 기존 앱을 계속 쓸 수 있으며 같은 버전의 자동 안내만 24시간 미룹니다. 복귀 시 버전 확인은 계속하며 새 버전·필수 업데이트는 이 유예에 가려지지 않습니다. 수동 확인은 유예를 무시합니다.

예약 방식 호환성이 깨지는 경우 배포 메타데이터의 `minSupportedVersionCode`를 올립니다. 설치 버전이 그 값보다 낮으면 새 실제 예약 실행만 제한합니다. 기존 작업·저장 정보·읽기 전용 조회·모의 테스트·중지는 유지합니다. 숫자상 큰 버전이라는 이유로 필수 업데이트로 판단하지 않습니다. 0.4.1 배포의 최소 지원은 5이며 기존 0.3/0.4 사용자는 선택 업데이트입니다. 이 정책은 0.4.1부터 적용되므로 그보다 오래된 앱에는 최초 한 번 직접 설치가 필요할 수 있습니다.

GitHub APK 다운로드 후 Android 설치 승인은 사용자가 직접 합니다. 업데이트 서버에 예약자 정보·HA 토큰·사이트 쿠키를 보내지 않습니다. 자동 확인 실패는 강제 설치나 데이터 삭제로 이어지지 않으며 수동 확인에서 실패를 안내합니다.

## 내부 구조와 저장

로컬 UI WebView에만 제한된 JSON 인터페이스가 있으며 원격 예약 WebView에는 인터페이스가 없습니다. 원격 엔진은 HTTPS의 허용된 공식 경로만 사용합니다. 혼합 HTTP·임의 외부 경로·원격 파일 접근을 차단합니다.

예약자·일정·모드별 초안·조회 결과·사진 목록은 Android Keystore AES-GCM으로 암호화해 앱 내부에 저장합니다. 사진 자체는 크기를 제한해 앱 전용 파일로 보관합니다. 클라우드 백업·기기 간 추출·분석/광고는 비활성화했습니다. 복호화 실패 시 자동 초기화하지 않습니다. 앱 삭제 시 데이터와 키도 삭제됩니다.

## 빌드와 테스트

JDK 17, Android SDK Platform 36 / Build Tools 35.0.0 이상이 필요합니다.

```sh
./gradlew :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
node --test test/*.test.cjs
adb -s emulator-5556 install -r app/build/outputs/apk/debug/app-debug.apk
adb -s emulator-5556 install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s emulator-5556 shell am instrument -w kr.swim.phone.test/kr.swim.phone.EngineTestRunner
```

브라우저 테스트는 playwright-core와 Chrome이 필요합니다. 테스트 러너는 전용 에뮬레이터에서만 실행하세요. 알림/알람/절전 예외를 변경하며 종료 시 강제 절전과 가상 배터리는 복원합니다. adb 종료 코드만 보지 말고 `assertions passed`를 확인해야 합니다. 테스트 예약·조회는 모의 페이지에서만 수행합니다. 모의 검증은 실기기 실제 예약 성공을 증명하지 않습니다.
