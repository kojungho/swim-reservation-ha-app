## 업데이트 전용 네이티브 테스트: 14개 통과

전용 에뮬레이터에 모의 공개 메타데이터를 제공했다. APK 다운로드·설치나 실제 예약 요청은 테스트하지 않았다.

- 실제 HOME 이동 후 이미 실행 중인 같은 Activity 복귀 시 재확인. 하루/5분 제한 없음.
- 디자인 변경은 선택 업데이트이며 ‘나중에’ 제공. 기존 앱 사용 허용.

- 최소 지원 코드 미달 시 새 실제 예약 실행 제한. 실제 스케줄러에서도 실행 전 차단됨.
- 진행/대기 중 예약은 확인·중단·초기화하지 않음.
- 수동 확인의 네트워크 실패 표시, 중복 복귀/수동 요청은 하나로 합침.

## 배포 정책

이번 배포는 선택 업데이트이며 minSupportedVersionCode=5다. 0.3/0.4 기존 기능을 강제로 막지 않는다. 이후 예약 방식 호환성이 깨지는 배포에만 최소 지원 코드를 올린다. 숫자상 큰 버전 또는 디자인 변경만으로 필수 업데이트로 판단하지 않는다. 진행 중 작업을 강제 중단하거나 저장 정보를 삭제하지 않는다.

복귀 확인·선택 유예·필수 호환성 제한은 0.4.1부터 동작하므로 이전 앱에는 최초 한 번 직접 업데이트 설치가 필요할 수 있다.
