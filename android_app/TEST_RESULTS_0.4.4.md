# 0.4.4-preview · 달력·화면별 초기화·앱 내부 업데이트

검증일: 2026-10-25. versionCode 10 / 최소 지원 코드 5 유지, 선택 업데이트.

- 앱·애드온이 같은 달력 모델 사용. 가능 수·마감·예정·미확인 표시, 과거 날짜 차단. 12/17 입실·12/18 퇴실은 1박으로 허용하며 12/18 마감이면 12/19 퇴실은 차단한다. 취소 대기는 마감일도 선택 가능하다.
- 미공개 날짜는 예정으로 후보 지정 가능하지만 즉시 예약을 허용하지 않는다. 공식 오픈 시각 확인과 실행 시각 지정 또는 취소 대기 등록이 필요하다. 예약 성공이나 오픈 시각 정확성을 보장하지 않는다.
- 날짜별 수량만으로 같은 사이트의 연박을 추측하지 않는다. 전체 기간의 읽기 전용 조회로 사이트별 연박 가능/불가를 표시한다. 앱은 조건 변경 후 진행 중 작업·알림 권한을 확인하며 조회한다.
- 초기화는 현재 예약 모드의 입력만 지우고 다른 모드 초안·저장 예약자·등록 일정은 보존한다. 초기 상태와 같거나 예약 입력 화면이 아니면 버튼을 숨긴다.
- Android 내부 저장소로 다운로드, HTTPS GitHub 호스트/리다이렉트 제한, 최대 크기·완전 수신 확인, SHA-256(메타데이터 제공 시)·패키지·상위 버전·기존 서명 검증 후 Android 설치 화면에 읽기 전용 URI로 전달한다. 취소·실패 시 부분 파일을 제거한다. 알 수 없는 출처 허용과 최종 설치 확인은 사용자 조작이 필요하다.
- 브라우저 UI 6개, 애드온 달력/초기화/기존 날짜 UI 10개 통과.
- 확대 회귀: 애드온 선택·정렬·날짜·초안·연결 복구·실제 로컬 HTTP API 검증도 통과. 새 달력 스크립트의 실제 서버 정적 제공을 추가하고 404 회귀를 해결했다. 동시 브라우저 기동 시 발생한 시간 초과 2개는 단독 재실행에서 통과했다.
