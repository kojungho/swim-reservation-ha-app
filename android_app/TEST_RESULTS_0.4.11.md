# 실행 상태와 예약 조회 알림 검증

- JVM/Robolectric 23개: 기존 16개와 신규 7개 통과. 빈 다인 대상은 FAILED, 빈 객실은 NO_ROOM, 부분 완료는 검증된 영수증 건수만 입금 대기로 표시. 조회 실패와 내역 없음 구분, 입금 대기/확정/취소 집계, 모의 알림, 조회 PendingIntent 대상, 대기 중지 시 알림 교체, 이전 0/0 보정과 자동 재예약 차단, 조회 알림의 독립 ID 검증.
- Chromium UI 14개 통과. 알림 요청 시 편집 내용을 보존하고 예약 조회 화면을 한 번만 열며 예약/조회 요청을 자동 제출하지 않는지 확인.
- Android release/test APK 빌드, lint 및 기존 JVM 검사 성공. 기존 0.4.10 자동취소 조회 수정 포함.
- 실제 신규 예약/입금/취소는 실행하지 않음. Android 알림 표시·실제 알림 탭·백그라운드 시스템 동작은 실기기 미검증이며 Robolectric과 브라우저 검증으로 구분.
- 소스 0.4.11 / versionCode 17. 기존 서명 키가 없어 설치용 업데이트 APK는 배포하지 않음. 공개 update.json과 APK는 0.4.7 유지. 맥북에서 기존 키로 서명해야 사용자 폰에 반영됨.
