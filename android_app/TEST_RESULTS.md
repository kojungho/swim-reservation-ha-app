## 실제 사이트 읽기 전용 연결 확인

실제 예약 사이트에 객실 목록 GET 조회만 수행했다. 예약자 개인정보 입력·약관 전송·최종 예약·예약 취소는 수행하지 않았다.

현재 개발 환경 결과: `FAILED / 사이트 HTTP 403 · 중지했습니다.`

따라서 현재 APK는 **폰 내부 엔진 검증용 첫 버전**이다. 실제 사이트에서 정상 예약까지 완료했다고 검증하지 않았다. 사용자 폰에서 ‘객실 조회만’을 먼저 확인해야 하며, 403·429 제한이 계속되면 공식 사이트의 허용 조건·안내를 확인해야 한다. 프록시·신원 변경·인증서 무시 등 제한 우회는 구현하지 않았다.
