3개 테스트 통과, 실패 0. 320 / 390 / 1280px 화면을 검사했다.

- 화면 화살표 없음, 44px 드래그 손잡이·촘촘한 행 간격.
- 키보드·마우스 정렬, Escape 및 터치 취소 복원, DOM 이동 후 포인터 캡처 유지.

- 다인 정보·우선순위·일정 등록, 다중 모드, 조회·월별 개수·사진 관리의 네이티브 요청 연결.
- 모드 전환 초안 복원, 완료 초안만 초기화, 새 편집 초안 보존, 명시적 초기화 시 저장 예약자 유지.
- 모바일 화면을 캡처해 목록 높이·손잡이·순위·가능 여부 표시를 확인했다.

## 네이티브 에뮬레이터 검증

전용 에뮬레이터에서 94개 검증을 통과했다. 모의 페이지로만 예약·조회했으며 실제 예약 요청·취소·입금은 하지 않았다.

- 다중 2사이트 및 다인 2예약자의 격리된 순차 예약·영수증 대조 성공. 각 세션은 1회만 제출했다.
- 첫 작업 429 시 남은 작업 제출 중지.
- 원본 조회 폼과 개별 상세 POST 2건 대조, 명시적 예약 없음과 조회 실패 구분.
- 월별 0곳/가능 개수, 서버 시각 보정 범위, 사진 디코딩·개인 저장·적용·기본 복원·삭제.

- 날짜 불일치·오픈 전·429·영수증 불일치·사용자 중지·프로세스 복원·재부팅 시 중복 제출 차단.

- 모의 테스트는 사용자 S25의 실제 예약 성공·장시간 감시를 증명하지 않는다.
