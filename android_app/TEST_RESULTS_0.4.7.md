# 0.4.7 · 앱·애드온 배치도 사진 추가·다운로드

- 앱 0.4.7 / versionCode 13, HA 애드온 2.15.12. 최소 지원 코드 5 유지, 선택 업데이트.
- 두 UI의 위쪽 사진 등록 버튼은 숨기고 목록 마지막 ‘＋ 추가’만 제공한다. 0장·기존 사진·6장 한도·삭제 후 재활성화를 브라우저 320/390/1280px에서 확인했다.
- 애드온 사진 카드마다 다운로드 링크를 제공한다. 실제 로컬 HTTP 서버에서 Content-Disposition/Content-Length/PNG 내용과 Chrome 다운로드 완료 파일을 검증했다. 다운로드 후 이력·적용 상태는 유지된다.
- 폰 사진마다 다운로드 버튼은 native mapExport로 연결한다. Android ACTION_CREATE_DOCUMENT 저장 위치 선택창 사용; 광범위 저장소 권한이나 외부 브라우저 없이 JPEG 저장. 등록한 파일 그대로 내보내며 등록 이전 촬영 원본 복원은 아니다.
- Android 에뮬레이터 검증 10개 통과: 저장 내용 동일, 목록·적용 보존, 미등록/잘못된 경로 거부, 시스템 저장 선택 Intent·MIME·파일명, 위쪽 버튼 숨김, 아래 버튼 하나, 사진별 다운로드 및 예약 엔진 미실행.
- 브라우저 앱 UI 7개 통과. 애드온 사진·설정·실제 API 관련 11개 통과. 다운로드 브라우저 검증은 가상 HTTPS 라우트가 아닌 실제 로컬 HTTP 서버에서 수행하여 실제 파일 내용과 완료를 확인했다.
- 전체 220개 첫 실행 중 218개 통과. 가상 HTTPS 다운로드 테스트를 실제 HTTP 서버 검증으로 이동했고 해당 8개 묶음 통과. 병행 작업 중 시간 초과된 상태 요청 테스트는 단독 재실행 통과. 최종 전체 재검증 진행.
- assembleDebug / assembleDebugAndroidTest / lintDebug 성공. lint 오류 0, 기존 경고 4개. 실제 캠핑장 예약·취소는 실행하지 않았다.
