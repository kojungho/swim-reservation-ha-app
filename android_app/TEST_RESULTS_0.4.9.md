# 0.4.9 · 공통 선택창·플로팅 오류·달력·동시 일정

- 브라우저 앱 UI 13개 통과. 320/390/1280px 사이트 다중 선택의 완료 전 불변·완료 일괄 적용·취소 유지, 하단 오류, 숨긴 약관 체크와 내부 필수 동의, 달력 재열기/월 이동/실패 재시도, 대기 중 조회 및 여러 일정의 버튼 용량을 확인.
- JVM/Robolectric 12개 통과: 정확한 한국 시간 안내 4개, 동시 일정 수명 8개. 5개 모의 엔진 동시 실행·6번째 거부, 하나만 중지, 일정별 제출 마커와 중복 제출 거부, 각 알람 식별/미래 알람 복원, 대기 중 달력 조회, 동일 일정 중복 시작·미지원 프로필 거부, 완료 이력 재시작 거부와 미확인 예약 겹침 차단/공식 내역 확인 후 해제를 검증.
- Robolectric은 Android 런타임을 모의하며 엔진과 프로필 지원 여부 및 Keystore 키를 테스트 대역으로 제공. 실제 AES-GCM 암복호화는 사용하되 하드웨어 Keystore·실제 System WebView 프로필·실기기 알람 정시성·캠핑장 실예약은 검증하지 않음.
- AndroidX WebKit MULTI_PROFILE 지원 기기에서 일정별 프로필과 쿠키를 사용. 미지원 시 한 건만 허용하고 업데이트 안내. 알람·실행 상태·제출 마커·취소·로그는 일정별 저장소로 분리. 다인·다중의 한 일정 내부 하위 예약은 순차 실행.
- 관련 애드온 회귀 23개 확인. 최초 실행의 예약자 복원 검증이 초기 DOM을 먼저 읽는 문제는 구성 복원 완료까지 기다리도록 바꾸고 해당 테스트 재실행 통과. 실제 예약·취소·결제는 실행하지 않음.
- 기존 앱과 같은 서명 키가 없어 APK 업데이트를 게시하지 않음. update.json은 0.4.7 유지. 맥북에서 main 최신 소스를 기존 키로 빌드·서명한 뒤 배포해야 함.

- 이전 버전의 활성 실행은 구성 스냅샷이 같은 저장 일정이 정확히 하나인 경우에만 ID를 연결. 일치가 없거나 여러 개면 임의로 선택하지 않고 새 시작을 막으며 전체 중지 안내. 복원·중복 시작 차단 2개 테스트 추가 통과.
