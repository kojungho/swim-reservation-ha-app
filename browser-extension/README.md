# 쉼오지 예약 도우미

쉼오지캠프 예약 페이지용 Chromium 확장 프로그램입니다. 객실 우선순위, 박수, 예약자명, 입금자명, 휴대폰 번호, 생년월일을 브라우저 로컬 저장소에 저장하고 지정 시각에 예약 흐름을 진행합니다. 숙박 시작 날짜를 선택하면 예약 링크의 `adaystart` 값과 예약 오픈 예정 시각을 자동으로 계산합니다.

## 설치

Mac과 Windows의 Chrome 및 Edge에서 사용할 수 있습니다. Chrome은 주소창에 `chrome://extensions`, Edge는 `edge://extensions`를 입력합니다.

5. Chrome 도구 모음에서 **쉼오지 예약 도우미** 아이콘을 누릅니다.

## 사용

1. 실제 숙박 시작 날짜를 달력에서 선택합니다. 예약 링크는 자동 생성됩니다.
2. 자동 제안된 실행 시각을 확인합니다. 사이트 규칙에 따라 숙박월 두 달 전 1일 00:00:00으로 계산됩니다.
3. 원하는 객실에 체크한 뒤 화살표로 우선순위를 정합니다.
4. 박수와 예약자 정보를 입력하고 **설정 저장**을 누릅니다.
5. **예약 대기 시작**을 누르고 예약 시각까지 Chrome과 Mac을 켜 둡니다.

예약 시각이 되면 페이지를 새로 열고, 우선순위 중 선택한 박수로 예약 가능한 첫 번째 객실을 사용합니다. 마지막 자동 제출을 끄면 개인정보 입력까지만 하고 멈춥니다.

## 주의

- 첫 실전 사용 전에는 마지막 자동 제출을 끄고 입력 단계까지 정상 진행되는지 확인하는 것을 권장합니다.
- 사이트 화면이나 입력 필드가 변경되면 확장 프로그램도 수정이 필요할 수 있습니다.
- 사이트는 HTTP 연결을 사용하므로 전송되는 개인정보가 HTTPS로 암호화되지 않습니다.
- 이 프로그램은 한 번의 정상 예약 절차만 수행하며, 서버에 반복 요청을 보내는 방식은 사용하지 않습니다.
- 스마트폰 브라우저는 화면이 꺼지거나 앱이 백그라운드로 이동하면 정밀 타이머가 중단될 수 있어 00시 자동 실행을 보장할 수 없습니다. 모바일 단독 실행판은 별도 방식이 필요합니다.
